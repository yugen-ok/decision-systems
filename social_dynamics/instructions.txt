# 🔧 CHANGE SET (minimal, concrete)

We keep:

* primitives (L, M, R, V) ✔️
* score function ✔️
* optimization ✔️
* flow composition ✔️

We change only 3 things:

1. targets
2. weights
3. (slightly) state structure

---

# 1️⃣ Replace fixed targets → relational targets

## ❌ REMOVE

In `core_dynamics.py`:

```python
targets = self._init_targets()
```

and everything that assigns fixed vectors.

---

## ✅ ADD: positions per character

Instead of ONE global `x`, split it:

```python
state.positions = {
    "Red": vector,
    "Liz": vector,
    "Tom": vector,
    ...
}
```

Each character now has a **position in the same space**.

---

## ✅ DEFINE targets from relationships

### Red (manipulator)

```python
target_Red = pos_Liz - pos_Tom
```

Meaning:

> push Liz away from Tom (core S1 dynamic)

---

### Liz (amplifier / investigator)

```python
target_Liz = pos_Red - pos_Liz
```

Meaning:

> move toward Red (curiosity / pull)

---

### Tom (stability / concealment)

```python
target_Tom = pos_Liz - pos_Tom
BUT with negative weight (α < 0)
```

Meaning:

> resist exposure, stay embedded

---

### Ressler (direct pursuit)

```python
target_Ressler = pos_Red - pos_Ressler
```

Meaning:

> chase Red directly

---

### Cooper (regulator)

```python
target_Cooper = average(pos_all) - pos_Cooper
```

Meaning:

> stabilize system center

---

## 🔑 What changed

Before:

> “Red wants point X”

Now:

> “Red wants **a relation between Liz and Tom**”

→ if Liz/Tom move → Red’s goal moves
→ no fixed endpoint anymore

---

# 2️⃣ Replace fixed weights → performance-based weights

## ❌ REMOVE

```python
weights["Red"] *= 1.001
```

---

## ✅ ADD: success-based update

After computing directions:

```python
alignment = dot(e_k, F)
```

Then:

```python
if alignment > 0:
    weight *= 1.01
else:
    weight *= 0.99
```

---

## 🔑 Meaning

* if a character’s direction **matches actual system movement** → grows
* if not → shrinks

So:

> influence emerges from effectiveness

---

# 3️⃣ Slight structural change: compute flow per character position

Right now:

```python
F = Σ a_k e_k
x = x + F dt
```

---

## ✅ Replace with

Each character moves:

```python
pos_k += a_k * e_k * dt
```

---

## 🔑 Meaning

* characters actually move in space
* relationships update naturally
* targets shift automatically

---

# 4️⃣ Add antagonists (very important)

This will actually make emergence much stronger.

---

## 🧨 Berlin (pure disruptor)

```python
alpha = 0
beta = 0
gamma = 1.5
eta = -1
```

Interpretation:

* no goal
* strong amplification
* seeks boundary crossing

Target:

```python
target_Berlin = random_direction OR pos_Red - pos_Berlin
```

Effect:

> injects chaos + forces inflections

---

## 🏛 Government / Cabal / Senate

Model as a **field**, not a character:

```python
n_boundary = function_of(x)
```

Instead of fixed boundary:

```python
n = gradient_of_constraint_field(x)
```

Meaning:

> constraints emerge depending on system state

Example:

* if system gets too unstable → stronger constraint
* if calm → weaker

---

# 5️⃣ (Optional but strong) normalize targets

To avoid explosion:

```python
target = target / (norm(target) + ε)
```

---

# ✅ FINAL SYSTEM (clean)

### At each step:

1. For each character:

   * compute target from others
   * compute ∇φ from that

2. Find best direction e_k

3. Compute flow:

   ```python
   F = Σ a_k e_k
   ```

4. Update positions:

   ```python
   pos_k += a_k * e_k * dt
   ```

5. Update weights:

   ```python
   based on alignment with F
   ```

  * power fixed

### After

* conflict emergent ✔️
